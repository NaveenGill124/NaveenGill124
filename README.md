## 📚 Research & Publications

### 🥇 **LLM-FS: Zero-Shot Feature Selection for Effective and Interpretable Malware Detection**
**Best Paper Award — IEEE BuildSec 2025 (International Conference)**  
A zero-shot LLM-based feature selection framework evaluated on **EMBER + BODMAS** datasets.  
✅ Outperformed **Chi², Mutual Information, ANOVA, ExtraTrees** in **Accuracy** and **MCC**  
✅ Improves interpretability through reasoned feature selection  
🎤 Presented at IEEE BuildSec 2025  
🔗 *(Repo coming soon)*

---

### 📝 **LLM-Guided Feature Selection with Empirically Optimal Feature Subset Size: A Generalization Study on Malware Detection**
📌 **Submitted to RECCAP 2026**  
Proposes a **generalization-driven LLM feature selection strategy** using empirically optimal feature subset size.  
Focuses on bridging:
- Overfitting vs generalization gap
- robustness across multiple malware datasets
- stability of LLM-selected features  
🔗 *(Under Review)*

### **🗂️ Project Samarth — Multi-Source Government Data Reasoning Agent**
A LangChain-powered multi-step reasoning system that unifies climate, agriculture, and census datasets into a single queryable intelligence layer.  
Built a retrieval-augmented pipeline with semantic search, FastAPI backend services, and a React prototype for real-time policy insights and explainable analytics.  
🔗 [GitHub Repo](https://github.com/NaveenGill124/govt_data_project)
